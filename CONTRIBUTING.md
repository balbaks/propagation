# Contributing

Thanks for your interest in Propagation. Small changes and bug reports are very welcome. To contribute:

- File an issue describing the problem or feature you want.
- Fork the repository and make a branch named `fix/...` or `feature/...`.
- Open a pull request with a clear description of the change.

Guidelines

- Keep changes small and focused; one logical change per PR.
- Include screenshots or short recordings for UI/visual changes.
- If you change simulation constants or rendering behavior, explain why and include before/after images or measured performance impact.
